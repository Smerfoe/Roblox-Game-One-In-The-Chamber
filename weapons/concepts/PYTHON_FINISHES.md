# Python rare finish proposals

`PythonRareFinishes.png` is cosmetic concept art only, not production meshes, UVs, textures, unlocks or a live crate. All four proposals use the same intended Python-style revolver silhouette. Illustration inconsistencies are not instructions to change geometry.

| Finish | Direction | Production constraint |
| --- | --- | --- |
| Eclipse | Black polished metal with fine gold line engraving and a dark grip | Flat texture detail; no added ornaments |
| Opal Vein | Pearlescent silver with ivory-tone grip and mineral-like blue veins | Controlled reflectance, no emissive bloom |
| Crimson Regent | Burgundy metal, fine gold detailing and dark wood | Restrained highlights; no flashing/animated light |
| Aurora Titanium | Teal/violet heat-treated metallic look and black grip | Static finish; no aura or distracting color animation |

The user suggested these might eventually suit a **0.1% chance** crate tier. That is a proposed rarity target, not implemented odds or a promise. Do not add a crate, paid purchase, inventory grant or drop-rate setting from this concept task.

All production versions must reuse the exact baseline mesh transforms, sight geometry, animations, hitbox policy and server stats. Matte dark sights remain readable. No particles, larger silhouette, dangling charms, transparent frame, extra sound advantages or altered attack/reload timing. A finish cannot extend range or change damage. Review opponent visibility in varied lighting as well as local first-person visibility; cosmetics must not conceal players or obscure aim.

These ornate finishes cannot be reproduced faithfully by simply recoloring this native-part prototype. Final engraving/pearlescence needs approved source meshes, UV/material work and Roblox material validation. Do not turn the illustration into a weapon model by adding random small parts. First approve a finish, then create an original texture/material set for the actual production asset.
